迪迦额度显示器 v2.0.0：集成说明（2026-10-17）

宿主使用独立 Electron，账号资料位于 %LOCALAPPDATA%\TigaEnergyMonitorV2。旧版仅迁移 refreshSeconds / warningThreshold / alwaysOnTop。不会读取或复制原 Codex、Claude 的登录凭据。两个自动唤起选项默认关闭；开发和测试模式不会注册启动项。

主界面为 420×246 DIP 透明无边框悬浮窗，默认置顶、不占任务栏、不主动抢焦点；缩放为80%/100%/125%/150%。账号管理和设置在独立560×720窗口中。位置单独保存到window-position.json，重启后恢复并限制在有效显示器工作区。三态预览仅存于内存，不能改变真实额度或账号状态。人物和文字的原生形状区域之外允许鼠标穿透；区域由主界面提供，宿主校验范围与数量并随缩放向外取整，设置窗口仍为普通矩形。

Codex 使用随附官方 app-server，以及旧版 C++ 核心的额度解析和能量判定。Claude 使用未改动的官方 Claude Code 2.1.292，通过 auth login 打开官方授权流程，通过 auth status 查询登录状态；登录凭据由官方组件保存在独立 CLAUDE_CONFIG_DIR。

Claude 额度读取是实验性兼容功能：通过 ConPTY 打开官方 /usage 界面并严格解析 Current session / Current week 数据，不调用未公开 HTTP API，不发送生成请求。首次官方设置、界面文案变化或暂时没有额度时返回 quota_pending；打开官方用量网页本身不会被标记为已连接。检测到首次信任/条款/登录设置时返回 needsSetup；用户点击“完成官方首次设置”才打开可见的原版官方终端，使用同一独立profile。不会替用户接受提示；终端关闭后重新读取官方状态。未经用户实际登录，登录后额度读取尚未端到端验证。缺少准确时区的重置时间保留 resetLabel，不猜测时间。

备用 importStatusLine 接口只解析官方文档中的 rate_limits.five_hour / seven_day 字段；该字段通常只在支持订阅计划的会话首次响应后出现，不能当成独立后台查询接口。
