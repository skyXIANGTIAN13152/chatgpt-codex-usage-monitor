# 主题素材与绘制边界

用户最终指定的红灯原图决定胸甲、银色包边、中央胸灯、裁切和全部比例。警告亮相位直接使用该文件；不再以低分辨率旧素材重画或近似模拟。

最终 EXE 内嵌红灯原图及三个同源状态版本。蓝灯版本只把内置图像编辑生成的蓝色镜片、金属环和紧邻反光柔边合回主图；暗相位只处理红色镜片；石像版本统一处理整幅图。它们只用于左侧主题区域，运行时仅进行等比缩放、定位、整体透明度与边缘淡化。

警告亮相位由 `tiga_chest_master_red.png` 原样复制，因此与用户指定图片逐像素一致。蓝灯和暗相位的所有改动被测试限制在中央灯区；0% 状态对整幅原图统一去饱和、压低对比并加入极轻的确定性颗粒，模拟失去颜色、金属光泽和灯光后的哑光石像。状态图由 `scripts/generate-theme-variants.ps1` 生成，能量条与文字状态动效仍由 Direct2D 实时绘制。

## “致以光辉的人”背板

背板不使用第二张主题图片，而由 Direct2D 原创绘制：深靛暗夜从左向蓝紫与暖金黎明过渡；十枚大小不一的金色/蓝白光点代表普通人的光，并由五束极细光线指向左侧胸灯；底部两条贝塞尔光轨分别使用暖金与蓝银，外框则从蓝、紫过渡到金。这些装饰避开百分比、进度条和状态文字的主要对比区域。石化状态把全部光效压至 24%，边框同步变成中性银灰。

光点、光束、光轨和渐变均只在窗口原本需要重绘时绘制，不增加新的动画计时器或持续帧循环。

## 量子离子字体

主百分比采用五段纵向等离子渐变：冰蓝外层、白色高能核心、青色电离带、二次白光和紫蓝收边。文字轮廓先以八方向紫蓝外辉和四方向青色内辉凝聚，再覆盖高对比能量核心；RESET、设置与最小化使用同一材质但降低辉光强度，绝对重置时间和次要信息使用低亮冰蓝。

字体周围不再散布金屑或十字星。百分比只绘制四个结构化离子，RESET 只绘制两个：每个离子由淡色光晕、带电外层、白色核心及一条椭圆轨道或短拖尾组成。位置由固定种子生成并限制在字框上沿 8%–20% 或下沿 80%–92%，不会进入数字阅读中线；百分比横向范围仍按字符数收紧，避免 0% 被误读为带前置标点。

量子材质与状态机联动：正常态为青蓝白与少量紫色；WARNING/CRITICAL 改为白热粉、绯红和洋红，并沿用原有红灯明暗相位同步压低辉光；STONE 完全关闭离子，只显示低亮冷灰休眠文字。状态行仍保留绿色 LIVE、红色 WARNING 和灰色 STONE，只叠加对应状态的微弱离子辉光，既统一材质又不牺牲识别。全部效果只随原有窗口重绘更新，不新增持续动画。

## 应用与托盘图标

程序资源内嵌透明背景的器物图标，并由同一透明 PNG 生成九档 Windows ICO 画面。16–24 像素只保留最有识别度的 U 形上部；32–48 像素加入金色底座；64–256 像素显示完整器物。所有尺寸均保留透明四角，不使用白色底板，并分别供 EXE、窗口类和系统托盘按实际 DPI 选择。图标生成脚本位于 `scripts/generate-app-icon.py`。

状态机：

- `NormalBlue`：蓝色稳定常亮，无定时器；
- `WarningRedBlink`：阈值以下红灯，1200/900/600 ms 分级；
- `CriticalRedFastBlink`：10% 以下 400/250 ms；
- `Stone`：0%，整幅胸甲与灯体统一哑光石化、静止；
- `DataUnavailable`：暗灰、无裂纹、静止，绝不冒充石化。
