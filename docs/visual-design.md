# 主题素材与绘制边界

用户最终指定的红灯原图决定胸甲、银色包边、中央胸灯、裁切和全部比例。警告亮相位直接使用该文件；不再以低分辨率旧素材重画或近似模拟。

最终 EXE 内嵌红灯原图及三个同源状态版本。蓝灯版本只把内置图像编辑生成的蓝色镜片、金属环和紧邻反光柔边合回主图；暗相位只处理红色镜片；石像版本统一处理整幅图。它们只用于左侧主题区域，运行时仅进行等比缩放、定位、整体透明度与边缘淡化。

警告亮相位由 `tiga_chest_master_red.png` 原样复制，因此与用户指定图片逐像素一致。蓝灯和暗相位的所有改动被测试限制在中央灯区；0% 状态对整幅原图统一去饱和、压低对比并加入极轻的确定性颗粒，模拟失去颜色、金属光泽和灯光后的哑光石像。状态图由 `scripts/generate-theme-variants.ps1` 生成，能量条与文字状态动效仍由 Direct2D 实时绘制。

## “致以光辉的人”背板

背板不使用第二张主题图片，而由 Direct2D 原创绘制：以胸灯为中心的蓝白光晕向深靛底色自然扩散，下方只保留低对比的柔和反光。胸甲底缘使用透明度渐变融入背板，灯区、原图比例与构图不变。移除独立的 U 形小图标、硬折线、切角和跨底栏光轨，避免像在原图下面另贴一层装饰板；外框降低亮度与线宽。石化时光晕变成低亮中性灰，红灯时光晕颜色稳定，不随镜片闪烁。主题参考：[圆谷官方迪迦角色介绍](https://tsuburaya-prod.com/heroes/ultraman-tiga)。原胸甲位图及其状态变体不作修改。

光晕与渐变均只在窗口原本需要重绘时绘制，不增加新的动画计时器或持续帧循环。

## 双额度光能层

圆环整体放在胸甲绘制区域右侧，并保留 6 DIP 的边界间距；圆环、百分比和右侧信息组一同右移，不压在迪迦身体上。单双圆环共用这一规则，纯额度模式不额外留空；窗口尺寸、胸甲、底栏按钮及进度条位置保持不变。间距与用户缩放和显示器 DPI 同比例变化。

默认按主额度的实际周期自动适配：只有周周期时隐藏内圈 / 下条及其整组文字；恢复两个周期时恢复双层。设置中保留“只显示周额度”。适配不改变原图、灯效、窗口位置、尺寸模式或整体缩放，也不会把 Spark 独立额度用作第二层。单圆环的百分比居中，右侧名称、倒计时与绝对时间组成居中的完整信息组；单进度条的重置倒计时与日期分行居中，避免在紧凑布局中碰撞。

周额度是长期基准，因此使用较深、较稳定的蓝紫色，固定对应圆环外圈或进度条上条；5 小时额度更接近即时能量，使用更亮的青蓝与白色高能核心，固定对应内圈或下条。两层都从十二点方向顺时针表示剩余百分比，并在末端保留一个高亮能量头。进入告警后，周额度使用深红层，5 小时额度使用更亮的绯红层；石化状态统一转为深浅灰。圆环和进度条不读取胸灯的明暗相位，因此警告时保持稳定，避免错误暗示额度数值正在变化。

双圆环中心以紧凑的 5H 数值标注内圈。右侧两组信息共享同一列对齐：名称左对齐、百分比右对齐，重置倒计时置于下一行；双进度条采用相同的信息次序。展开布局额外显示“深色/亮色”图例。切换为仅周额度后恢复单圆环居中百分比或单进度条大百分比，不保留空的第二层。离线时保留低亮灰色的最近额度，配合明确的离线提示，不把过期数据画成 0%。

紧凑版底部只保留状态与数据年龄，绝对重置时间、套餐和两层映射放入悬停提示。按钮统一采用矢量齿轮和减号，视觉中心与点击区域来自同一份布局计算；点击区域限制在底栏，不覆盖 5 小时的重置时间。设置菜单分组，选项可直接选择，不需要循环切换。

## 量子离子字体

单额度主百分比保留纵向等离子渐变：冰蓝外层、白色高能核心、青色电离带、二次白光和紫蓝收边。双额度较小的数字优先使用清晰的深浅冰蓝核心，避免缩小后辉光把字黏在一起；绝对重置时间和次要信息使用低亮冰蓝，设置与最小化改为明确的矢量按钮。

字体周围不再散布金屑或十字星。百分比只绘制四个结构化离子，RESET 只绘制两个：每个离子由淡色光晕、带电外层、白色核心及一条椭圆轨道或短拖尾组成。位置由固定种子生成并限制在字框上沿 8%–20% 或下沿 80%–92%，不会进入数字阅读中线；百分比横向范围仍按字符数收紧，避免 0% 被误读为带前置标点。

量子材质与状态机联动：正常态为青蓝白与少量紫色；警戒改为白热粉、绯红和洋红；石化完全关闭离子，只显示低亮冷灰休眠文字。红灯明暗相位只改变镜片，胸甲背景保持相同透明度；数字、额度图形和背板保持稳定。状态行保留绿、红、灰语义色，并直接使用同一个胸灯状态机，包含用户自定义的警戒阈值。全部效果只随窗口重绘更新，不新增持续动画；隐藏时停止胸灯闪烁计时器，后台额度刷新继续。

## 应用与托盘图标

程序资源内嵌透明背景的器物图标，并由同一透明 PNG 生成九档 Windows ICO 画面。16–24 像素只保留最有识别度的 U 形上部；32–48 像素加入金色底座；64–256 像素显示完整器物。所有尺寸均保留透明四角，不使用白色底板，并分别供 EXE、窗口类和系统托盘按实际 DPI 选择。图标生成脚本位于 `scripts/generate-app-icon.py`。

状态机：

- `NormalBlue`：蓝色稳定常亮，无定时器；
- `WarningRedBlink`：阈值以下红灯，1200/900/600 ms 分级；
- `CriticalRedFastBlink`：10% 以下 400/250 ms；
- `Stone`：0%，整幅胸甲与灯体统一哑光石化、静止；
- `DataUnavailable`：暗灰、无裂纹、静止，绝不冒充石化。
